# Scan Driven website

Single-page site for scandriven.com: a 3D scroll animation of a car being laser-scanned, the service steps, and a Cal.com booking embed.

- `npm install` then `npm run dev` to run it locally
- `npm run build` outputs the static site to `dist/`
- Netlify builds and deploys automatically from `main` (see `netlify.toml`)
